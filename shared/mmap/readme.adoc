 = File Chunking Utilities (`ChunkManager` & `mio_mapped_file`)
 :toc: left
 :source-highlighter: rouge
 :icons: font

 A C++ library providing utilities for splitting large files into smaller chunks and merging them back, along with an efficient memory-mapped file reader using an LRU chunking strategy.

 == Core Components

 *   `fm::mio_mapped_file`: Provides efficient read access to large files by mapping them in chunks with an LRU eviction strategy.



 == Design Overview

 === Memory Mapping Concept (`mio` / `fm::mio_mapped_file`)

 The library uses memory mapping to efficiently read large files without loading the entire content into RAM. The OS maps the file content into the process's virtual address space. Data is paged in from disk by the OS only when accessed.

```
 [source, ascii]
 ----
 +----------------------+          +-----------------------------+
 |      File on Disk    |          |   Process Virtual Memory    |
 | (e.g., large_file.bin)|         |                             |
 |======================|          |                             |
 |                      |          |   +---------------------+   |
 |   [ File Content ]   |          |   |   Mapped Region     |   |
 |   [   Block 0    ] <--------------> |   (File Block 0)    |   |
 |   [   Block 1    ] <--------------> |   (File Block 1)    | <---- std::span = mapped_file.get_span(...)
 |   [   Block 2    ] <--------------> |   (File Block 2)    |   |
 |        ...           |          |   |        ...          |   |
 |   [   Block N    ] <--------------> |   (File Block N)    |   |
 |                      |          |   +---------------------+   |
 |                      |          |                             |
 +----------------------+          +-----------------------------+
          ^                                      |
          |                                      |
          +------------- OS Memory Mapping ------>+
                        (Page Faults, Paging)

 ----


```
